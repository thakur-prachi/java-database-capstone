# User Stories

## Admin User Stories

**User Story 1**
As an Admin, I want to manage user accounts so that I can control access to the Patient Appointment Portal.

**User Story 2**
As an Admin, I want to manage doctor accounts so that only authorized doctors can use the system.

**User Story 3**
As an Admin, I want to manage patient accounts so that patient information and access are properly maintained.

**User Story 4**
As an Admin, I want to view and manage appointments so that I can monitor the overall appointment system.

## Patient User Stories

**User Story 1**
As a Patient, I want to register and log in so that I can securely access the appointment portal.

**User Story 2**
As a Patient, I want to view available doctors so that I can choose a suitable doctor.

**User Story 3**
As a Patient, I want to book an appointment so that I can consult a doctor.

**User Story 4**
As a Patient, I want to view my appointments so that I can keep track of my scheduled visits.

**User Story 5**
As a Patient, I want to cancel or reschedule an appointment so that I can manage my schedule.

## Doctor User Stories

**User Story 1**
As a Doctor, I want to log in securely so that I can access my appointments and profile.

**User Story 2**
As a Doctor, I want to manage my availability so that patients can book appointments during my available time.

**User Story 3**
As a Doctor, I want to view my appointments so that I can prepare for scheduled consultations.

**User Story 4**
As a Doctor, I want to view patient appointment details so that I can provide appropriate care.

**User Story 5**
As a Doctor, I want to update appointment status so that patients and the system have the latest appointment information.
